# README: Приложение Book Tracker (Трекер прочитанных книг)

**Автор**: Ларичева Эмилия

## Описание программы
*Book Tracker — это настольное графическое приложение (GUI) на языке Python, предназначенное для ведения личного списка прочитанных книг. Программа помогает структурировать информацию о литературе, сохранять историю чтения и быстро находить нужные книги в домашней библиотеке.*

## Основные функции и возможности:
1. **Учет книг**: Возможность добавлять название, автора, жанр и количество страниц.
2. **Валидация данных**: Встроенная проверка корректности ввода — программа не примет пустые поля или текст вместо количества страниц.
3. **Умная фильтрация**: Поиск по жанру или фильтрация списка по минимальному объему страниц (например, показать только книги длиннее 200 страниц).
4. **Автоматическое сохранение**: Все данные записываются в файл books_data.json в формате JSON, что позволяет сохранять информацию между сессиями работы программы.
5.  **Современный интерфейс**: Использование виджета Treeview для наглядного отображения списка в виде таблицы.

## Инструкция по запуску
Для работы программы требуется установленный интерпретатор Python версии 3.6 или выше.

1.  Скачайте исходный код: Сохраните код программы в файл с названием book_tracker.py.
2.  Откройте терминал: Перейдите в папку, где сохранен файл.
3.  Запустите программу:
    
    python book_tracker.py
    
    Примечание: Дополнительные библиотеки устанавливать не нужно, так как используется встроенный пакет tkinter.

## Примеры использования (Тесты)
Для проверки работоспособности программы можно выполнить следующие шаги:

1.  **Тест на добавление**: Введите данные: Название: "1984", Автор: "Джордж Оруэлл", Жанр: "Антиутопия", Страниц: "328". Нажмите «Добавить книгу». Книга должна появиться в таблице ниже.
2.  **Тест на ошибку ввода**: Оставьте поле «Жанр» пустым и попробуйте добавить книгу. Программа должна вывести предупреждение «Все поля должны быть заполнены!».
3.  **Тест на фильтрацию по объему**: Добавьте несколько книг с разным количеством страниц (например, 100 и 500). Введите в поле фильтра «Мин. страниц» число 300 и нажмите кнопку фильтрации. В таблице должна остаться только книга на 500 страниц.
4.  **Тест сохранения**: Закройте программу и откройте её снова. Все ранее добавленные книги должны загрузиться автоматически из файла JSON.
