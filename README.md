# README: Random Task Generator (Генератор случайных задач)
**Автор**: Ларичева Эмилия

## Описание программы
*Random Task Generator — это полезное графическое приложение, созданное на языке Python для помощи в планировании повседневных дел. Программа выбирает для пользователя случайную активность из списка предустановленных задач, помогая бороться с нерешительностью и прокрастинацией.
*

## Основные функции и возможности:
1. **Случайный выбор**: При нажатии кнопки программа мгновенно выбирает одну задачу из базы (например, «Сделать зарядку» или «Прочитать статью»).
2. **Учет истории**: Все сгенерированные задачи сохраняются в наглядный список-историю.
3. **Фильтрация по категориям**: Пользователь может просматривать историю только по конкретным типам задач: Учёба, Спорт или Работа.
4. **Постоянство данных**: Благодаря интеграции с форматом JSON, история не стирается после закрытия программы, а автоматически загружается при следующем запуске.
5. **Добавление своих задач**: Реализована возможность расширять список доступных задач через специальную форму ввода с проверкой на пустые строки.
## Инструкция по запуску
Для работы программы требуется установленный интерпретатор Python версии 3.6 или выше.

1.  Скачайте исходный код: Сохраните код программы в файл с названием book_tracker.py.
2.  Откройте терминал: Перейдите в папку, где сохранен файл.
3.  Запустите программу:
    
    python book_tracker.py
    
    Примечание: Дополнительные библиотеки устанавливать не нужно, так как используется встроенный пакет tkinter.

## Примеры использования (Тесты)
Для проверки работоспособности программы можно выполнить следующие шаги:

1. **Проверка генерации**: Нажмите кнопку «Сгенерировать задачу». В поле выше должен появиться текст задачи, а в списке истории — новая запись.
2. **Проверка фильтрации**: Выберите в выпадающем списке фильтра категорию «Спорт». Убедитесь, что в списке истории скрылись все задачи, кроме спортивных.
3. **Проверка валидации**: Попробуйте добавить свою задачу, оставив поле ввода пустым. Программа должна вывести предупреждение о некорректном вводе.
4. **Проверка сохранения**: Сгенерируйте задачу, закройте приложение и запустите его снова. Проверьте, что в истории осталась запись из прошлого сеанса.
